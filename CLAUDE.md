# Skills Library - Claude Instructions

This folder (`C:\Users\igori\skills\`) is the central skills library for building projects.

## Your Role Here
When working in or referencing this directory:
1. Always consult `README.md` to see available skills before starting a project
2. When building a project, read the relevant skill files in `library/`
3. When creating a new skill, use `templates/skill-template.md`

## Skills Available
See `README.md` for the full list of available skills.

## Key Paths
- Skills index: `C:\Users\igori\skills\README.md`
- Skill files: `C:\Users\igori\skills\library\<category>\<name>.md`
- Template: `C:\Users\igori\skills\templates\skill-template.md`
- Slash commands: `C:\Users\igori\.claude\commands\`

## When Starting a New Project
1. Ask the user what kind of project they want to build
2. Read the relevant skill(s) from `library/`
3. Apply the conventions, structure, and patterns from the skill
4. If no matching skill exists, suggest creating one with `/new-skill`
